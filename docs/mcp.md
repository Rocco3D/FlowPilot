# MCP server

`flowpilot mcp` starts a [Model Context Protocol](https://modelcontextprotocol.io) server over stdio. It lets AI assistants (Claude Code, Codex, Cursor, ...) generate videos and images through FlowPilot. It talks to the local HTTP API and starts the FlowPilot service whenever it is not running: on a first call, and again after an idle shutdown or a `flowpilot service stop`.

## Credit warning

Videos spend your Google Flow credits (Veo 3.1 Lite 10, Fast 20, Quality 100, Omni 1.1 Flash 4-15 depending on resolution and duration). Images with Nano Banana models cost 0 credits on the owner's plan. Jobs run one at a time. The tool descriptions tell the assistant to confirm with you before spending credits.

## Tools

| Tool             | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `generate_video` | Creates a video job. Fields: `prompt` (required), `model`, `ratio`, `duration`, `resolution`, `outputs`, `startFrame`, `endFrame`, `ingredients`, `characters`, `project`, `newProject` (`true`, or the name to give the new project), `outDir`, `upscale` (`original`, `1080p` (2K for images) or `4k`; left out, the best the user's Flow plan offers: 4K when the plan has it, else the 1080p/2K upscale, otherwise the original), `wait` (default true). There is no `confirm`: a job over a credit limit fails, and only you can let it through, with `--confirm` on the command line or `confirm` in the HTTP API. |
| `generate_image` | Same as `generate_video`, for images.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `get_job`        | Status and results of a job (`id`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `list_jobs`      | Recent jobs (`limit`, default 20).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `cancel_job`     | Cancels a job (`id`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `list_projects`  | Lists the Flow projects, most recent first, with `id` and `name`. While a job is running it fails with `job_running`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `delete_project` | Deletes a Flow project with all its media (`project`, its exact name or its id from `list_projects`). It cannot be undone. A partial name never matches, and a name two projects share fails with `project_ambiguous`. The tool description tells the assistant to ask you to confirm first, naming the project and its id, and to call it only after a clear yes. While a job is running it fails with `job_running`.                                                                                                                                                                                                   |
| `list_media`     | Lists the images and videos already in a Flow project (`project`, a name or id; left out, the most recent one), with `id`, `type` and `title`. It spends no credits. When a job is running, it waits for it to finish and `queued` is true.                                                                                                                                                                                                                                                                                                                                                                              |
| `download_media` | Downloads a media already in a Flow project (`mediaId`, from `list_media` or from a job; `project`; `outDir`; `upscale`; `wait`, default true). It generates nothing and spends no credits: the tool description tells the assistant to use it instead of generating the same media again. The file is saved as `<project>-media-<id>`.                                                                                                                                                                                                                                                                                  |
| `list_models`    | Available models with ratios, durations and credit costs. While a job is running, the list already read, or a `job_running` error when there is none yet.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `get_credits`    | Credits spent this month through FlowPilot, remaining credits and limits, plus the real Google Flow balance read from Flow (`flowBalance`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `selftest`       | Runs the service self-test. While a job is running it fails with `job_running`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `doctor`         | Checks Chrome and the Google Flow session. When a newer FlowPilot version is on GitHub, the result has an `update` field with a message for the user. When a configured default model is no longer offered by Flow, the result has a `configuredModels` field that names it and the successor that will be used. While a job is running, the model check is left for after the job and `message` says so.                                                                                                                                                                                                                |
| `get_config`     | Shows the configuration: default models, outputs per job, credit limits, language and where results are saved.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `set_config`     | Changes one setting (`key`, `value`). Only `defaultVideoModel`, `defaultImageModel`, `outputs` and `locale` can be changed, so a tool call cannot raise what the account spends.                                                                                                                                                                                                                                                                                                                                                                                                                                         |

With `wait` true the generation tools and `download_media` poll every 3 seconds, for at most 45 seconds, until the job ends, and return the job with the result file paths and, for a generation, the Google Flow balance left (`balance`). If the job is still running they return `{ still_running: true, id, status, hint }` and no error: nothing has failed, the job keeps running in the service, so call `get_job` again rather than generating it a second time. With `wait` false they return the job id and status. Errors are returned as MCP tool errors in the form `code: message`.

A finished job reports `modelUsed`, the model it really ran with. It differs from `request.model` when Flow no longer offered the configured model and the job ran with the next version of the same name; in that case the job also carries a `note` in words, and the configuration is updated unless it was changed while the job ran or could not be written; the note says which.

In `get_config`, a default model or a language that is not set comes back as `null`, not missing: "not set" is what makes a job use the model already selected in Flow, and an assistant has to be able to tell it from a setting that does not exist.

A generation that fails after finding its results in Flow (for example while downloading them) reports their ids in the error message for an image job (a video tile in Flow carries no id): `download_media` gets them back without spending credits again. Otherwise `list_media` finds them.

`list_media` opens each media in Flow's viewer to read its id, about two seconds per media, and waits for a running job first. Behind a long video the assistant's client may stop waiting before the list arrives; asking again works. An image also has a second id, the one the error of a failed job lists: `download_media` accepts both.

The descriptions of `generate_video` and `generate_image` tell the assistant to ask you, before the first generation of a conversation, whether to continue an existing project (from `list_projects`) or start a new one. With neither `project` nor `newProject`, the job runs in the most recent project, the first that `list_projects` returns.

`list_projects`, `list_models`, `get_credits`, `selftest`, `doctor` and `get_config` take no parameters and accept a call with no `arguments` at all, as the protocol allows, as well as an empty object. Tools that have parameters require them.

## Configuration

Claude Code:

```
claude mcp add flowpilot -- flowpilot mcp
```

Codex, Cursor and other clients that use a JSON configuration:

```json
{
  "mcpServers": {
    "flowpilot": {
      "command": "flowpilot",
      "args": ["mcp"]
    }
  }
}
```

Use `flowpilot --port <port> mcp` to target a service on a non-default port.

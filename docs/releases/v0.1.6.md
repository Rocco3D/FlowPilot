# FlowPilot 0.1.6

Thank you for using FlowPilot! Your feedback and bug reports make it better with every release.

## Fixed

- **Models Flow is about to retire.** Flow shows a note such as `Leaving Dec 5` under a model it is about to retire, and FlowPilot read the note as part of the name: `--model "Omni 1.1 Flash"` failed with `option_not_available`, and `--model "Omni 1.1 Flash Leaving Dec 5"` with `settings_not_applied`. The name is now read without the note in `models`, `doctor` and every job.
- **Models with a single length.** A video with `--model "Veo 3.1 - Lite" --duration 8` failed with `option_not_available` ("Available: none"), because Flow shows no duration chips for a model with one length. That length is now read from the settings in effect; asking for another one fails and names the length the model has.

The full list is in [CHANGELOG.md](https://github.com/Rocco3D/FlowPilot/blob/main/CHANGELOG.md).

## What was verified

Live, on macOS, in November 2026: `flowpilot models` lists `Omni 1.1 Flash`, `Veo 3.1 - Fast` and `Veo 3.1 - Quality` without the note. A video job with `--model "Omni 1.1 Flash" --duration 4` (7 credits) and one with `--model "Veo 3.1 - Lite" --duration 8` (10 credits) passed the settings check and were generated: 3.9 and 7.9 seconds, saved at 1920x1080.

Not verified: Windows and Linux, and a job saving its own video end to end: the two videos were saved with `POST /media/download`.

## How to update

Run these commands in the `FlowPilot` folder:

```bash
git pull
npm install
npm run build
```

Then run `flowpilot service stop`, and restart your AI assistant if you use FlowPilot through MCP.

# FlowPilot 0.1.3

Thank you for using FlowPilot! Your feedback and bug reports make it better with every release.

## Added

- **A model Flow retires no longer breaks your jobs.** If the model you configured as default (`defaultVideoModel`, `defaultImageModel`) is one Flow no longer offers, FlowPilot now picks the next version of the same name: `Nano Banana 2` becomes `Nano Banana 2.1`. The job tells you which model it used, your configuration is updated once so it does not happen again, and both steps are written to the log.
- **`doctor` checks your configured models.** Before you spend anything, `doctor` says which configured model Flow no longer offers and which successor it will use.
- **`--confirm` exists.** It is what the credit limit messages told you to use, and it is now a real flag on `video` and `image`.
- **Your assistant can read and change the configuration.** The MCP server gained `get_config` and `set_config`. An assistant can set the default models, the outputs per job and the language. The credit limits are deliberately not writable from a tool call: a tool that could raise `maxCreditsPerJob` would be a way to spend without asking you.
- **A job says which model it ran with.** The finished job reports `modelUsed`. It differs from the model you asked for when Flow had retired the configured one, so an assistant can read what actually ran instead of guessing from the text of the note.
- **Results belong to their job.** Each result is matched by its stable media id, so a job never picks up files left in the project by an earlier one.

## Changed

- `--max-credits` can only lower the per-job limit, never raise the configured one.
- `defaultVideoModel`, `defaultImageModel`, `outputs` and `locale` now do what the documentation says. The first three were documented but ignored.
- Chrome on the FlowPilot profile: FlowPilot says when it closed a Chrome you had open and reopened it with a debugging connection, instead of the window disappearing without explanation.
- MCP tools start the service again when they find it stopped, accept calls with no arguments, and wait at most 45 seconds for a long job before reporting it as still running.

## Fixed

- The local HTTP API rejects requests whose `Host` is not the service port, so a web page in your browser can no longer reach it.
- The HTTP errors returned a translation key (`http.notFound`) instead of a sentence. All six are translated now, and a test walks every key in the code so one cannot slip through again.
- A Chrome you opened yourself on the FlowPilot profile was not found by FlowPilot, so the automation launch landed in a tab of that window and no debugging port ever appeared: `doctor` reported a profile that looked broken while it was healthy. It is found, closed and reopened correctly now.

## How to update

`flowpilot doctor` tells you when this version is available. To update:

```bash
npm install -g Rocco3D/FlowPilot
```

From source, run `git pull`, then `npm install`. In both cases, run `flowpilot service stop` afterwards, and restart your AI assistant if you use FlowPilot through MCP.

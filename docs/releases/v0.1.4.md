# FlowPilot 0.1.4

Thank you for using FlowPilot! Your feedback and bug reports make it better with every release.

## Changed

- **FlowPilot is installed from a cloned repository.** `npm install -g Rocco3D/FlowPilot` no longer works: npm 12 refuses packages fetched from git by default (`EALLOWGIT`), and npm 10 on Windows installed the package without its compiled files, so `flowpilot` did not start. Installing from a clone works with both.
- **`doctor` tells you how to update from the FlowPilot folder:** `git pull`, `npm install` and `npm run build`.
- The `prepare` script is gone. npm 12 blocks it, and building is now an explicit step of installing and updating.

## How to update

If you installed FlowPilot with `npm install -g Rocco3D/FlowPilot`, remove it and install it from source:

```bash
npm uninstall -g flowpilot-cli
git clone https://github.com/Rocco3D/FlowPilot.git
cd FlowPilot
npm install
npm run build
npm link
```

Keep the `FlowPilot` folder: the `flowpilot` command runs from it.

If you already installed from source, run these commands in the `FlowPilot` folder:

```bash
git pull
npm install
npm run build
```

In both cases, run `flowpilot service stop` afterwards, and restart your AI assistant if you use FlowPilot through MCP.
